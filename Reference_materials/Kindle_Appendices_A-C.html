Appendix A The Ephemeris How-To — Swiss Ephemeris / pyswisseph
Astronomical Everything numeric in this book was computed, not recalled. This appendix lets the reader reproduce it. (Astronomy is verifiable; the interpretations remain unproven — Chapter 19.)

A.1 Installation

pip install pyswisseph --break-system-packages

A.2 The Julian Day (the time backbone)

All Swiss Ephemeris calls use Universal Time (UT) via a Julian Day number. Hours are decimal (10:30 → 10.5):

import swisseph as swe
jd = swe.julday(2026, 6, 22, 12.0)   # 22 Jun 2026, 12:00 UT

Caveat: convert local clock time to UT first (e.g., IST = UT + 5:30, so 18:14 IST → 12.733 UT). Birth/first-trade charts are time-sensitive (Chapter 13).

A.3 Tropical and sidereal positions

trop = swe.calc_ut(jd, swe.SUN)[0][0]                 # tropical longitude (deg)
swe.set_sid_mode(swe.SIDM_LAHIRI)                      # choose ayanamsa
ay   = swe.get_ayanamsa_ut(jd)                         # the ayanamsa value
sid  = (trop - ay) % 360                               # sidereal longitude
Astronomical Validated for 22 Jun 2026: Lahiri ayanamsa 24.2269°, KP ayanamsa 24.1300° (they differ by ~5.8′ — Chapter 2). Tropical Sun 91.10° → sidereal Sun 6.87° Gemini. For KP work use swe.SIDM_KRISHNAMURTI.

A.4 Sign, nakshatra, and pada from a longitude

signs = ["Aries","Taurus","Gemini","Cancer","Leo","Virgo","Libra",
         "Scorpio","Sagittarius","Capricorn","Aquarius","Pisces"]
sign  = signs[int(sid // 30)]            # 30° per sign
naks  = int(sid // (360/27))             # 27 nakshatras of 13°20′
pada  = int((sid % (360/27)) // (360/108))  # 4 padas per nakshatra

A.5 Speed, retrograde, and stations

lon, _, _, speed = swe.calc_ut(jd, swe.SATURN)[0][:4]
retrograde = speed < 0                    # negative longitude-speed = retrograde

A station is where speed crosses zero — scan day-by-day for a sign change in speed to date it (Chapters 7, 10).

A.6 Tithi (lunar day) and phase

sun  = (swe.calc_ut(jd, swe.SUN)[0][0]  - ay) % 360
moon = (swe.calc_ut(jd, swe.MOON)[0][0] - ay) % 360
tithi = int(((moon - sun) % 360) / 12) + 1   # 1–30; 1–15 waxing, 16–30 waning
Astronomical Tithi is zodiac-independent (a Sun–Moon angle) — it is identical in any ayanamsa (Chapter 6).

A.7 Combustion check (proximity to the Sun)

def gap_from_sun(jd, planet):
    s = swe.calc_ut(jd, swe.SUN)[0][0]
    p = swe.calc_ut(jd, planet)[0][0]
    d = abs((p - s) % 360); return min(d, 360 - d)
# compare to the planet's combustion orb (Appendix B.6)

A.8 Vimshottari mahadasha lord at birth

order = ["Ketu","Venus","Sun","Moon","Mars","Rahu","Jupiter","Saturn","Mercury"]
naks  = int(moon // (360/27))
birth_dasha_lord = order[naks % 9]      # from the Moon's nakshatra
Astronomical Validated: Moon 13.76° Virgo → Hasta (nakshatra #13) → birth mahadasha lord Moon. Full dasha dates require the elapsed fraction of the nakshatra at birth × the lord's years (Appendix B.4; Chapter 12).

A.9 Aspects / separations between two bodies

def separation(jd, p1, p2):
    a = swe.calc_ut(jd, p1)[0][0]; b = swe.calc_ut(jd, p2)[0][0]
    d = abs((a - b) % 360); return min(d, 360 - d)
Astronomical Separations and aspects are zodiac-independent — the Jupiter–Saturn angle is the same in tropical and sidereal (Chapter 2). This is why the Western cycle toolkit transfers unchanged.
A.10 — What needs more inputs Houses, ascendant, and KP sub-lord cusps require latitude, longitude, and exact time (swe.houses_ex with a house system such as Placidus for KP). These are the fragile layers (Chapters 13–14); planet-in-sign is the robust one.

C.3 The honest punchline of Appendix C

Observed Read the final column. The Jupiter–Saturn cycle — the book's "master clock" (Chapter 8) — stood at near-opposition in 1929, near-conjunction in 2000 and 2020, and mid-cycle in 1987 and 2008. The Suns span Libra, Aquarius, Leo, Pisces; the Jupiters span Taurus, Aries, Sagittarius. There is no single repeating planetary signature across the five great crashes. The most-cited "crash configurations" simply do not converge — exactly as Chapters 1 and 8 argued, and exactly what the always-on-sky combinatorics of Chapter 18 predict. The data in this very appendix is the cleanest refutation of a simple astrological crash-predictor — and the strongest case for the book's clock-not-compass, discipline-over-prediction thesis.
Observed Use these charts to study the relationship between sky and market history with honest, pre-registered scoring (Chapter 18) — never as a template to forecast or trade.
